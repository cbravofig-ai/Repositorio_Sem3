# A1 — Vectores de datos económicos

Crea y analiza vectores con información de salarios, nivel de educación y años 
de experiencia de un grupo de trabajadores, aplicando selección por posición, 
selección por condición, operaciones vectorizadas y estadísticas descriptivas.

## Datos

Los datos utilizados fueron creados para fines educativos y corresponden a un 
grupo ficticio de trabajadores con diferentes salarios, niveles de educación y 
años de experiencia. Los vectores se encuentran definidos directamente en el 
script `scripts/tarea_s3.R`.

## Cómo correrlo

1. Abrir `Repositorio_Sem3.Rproj`.
2. Abrir `scripts/tarea_s3.R`.
3. Ejecutar el script completo desde el inicio para reproducir todos los 
resultados.

**Importante:** Los archivos `semana3_lab_esqueleto.R`, `semana3_sesion1_guion.R` 
y `semana3_sesion2_guion.R` corresponden a guías y material de apoyo proporcionado 
durante las actividades de laboratorio. El desarrollo de la actividad evaluada 
se encuentra en `scripts/tarea_s3.R`.
